# 仓位管理

> 决定长期收益的不是"选到过多少牛股"，而是"如何在看错时活下来"。

## 一、仓位管理的三条底线

1. **单一标的不超过总仓位的 20%**：任何个股都可能出现停牌、暴雷、黑天鹅；
2. **单一行业不超过 35%**：行业景气反转时，个股相关性趋近于 1；
3. **永远保留现金**：现金是选择权，让你在极端行情中具备行动能力。

## 二、常用分配方法

| 方法 | 逻辑 | 适用人群 |
| --- | --- | --- |
| 等权分配 | 每个标的仓位相同 | 新手，简单有效 |
| 波动率加权 | 低波动标的多配 | 追求稳健 |
| 核心 + 卫星 | 60% 核心底仓 + 40% 择机 | 兼顾稳定与弹性 |
| 凯利公式 | 按胜率与赔率计算最优仓位 | 有稳定统计优势者 |

**凯利公式简化版：**

```text
f = (b × p − q) ÷ b
其中：b 为盈亏比，p 为胜率，q = 1 − p
```

实战中通常只使用**半凯利**（计算值的一半）甚至四分之一凯利，因为胜率与赔率的估计误差会被公式放大。

## 三、建仓节奏

**金字塔式买入（推荐）**

| 阶段 | 仓位 | 触发条件 |
| --- | --- | --- |
| 首次 | 1/3 | 逻辑成立、估值合理 |
| 第二次 | 1/3 | 回踩关键支撑不破，或逻辑被证实 |
| 第三次 | 1/3 | 突破关键位置放量确认 |

**倒金字塔（回避）**：越跌越买且越买越多，本质是把亏损放大，需要极高的资金厚度与判断力。

## 四、加减仓的纪律

- 加仓的前提是**逻辑未变 + 价格更优**，而不是"摊薄成本"；
- 减仓的顺序是**先减逻辑走坏的、估值最贵的、流动性最差的**；
- 反弹中减仓优于下跌中恐慌卖出；
- 任何加减仓操作都应有对应记录：触发条件、执行价格、事后复盘。

## 五、组合层面的检查表

| 检查项 | 阈值参考 |
| --- | --- |
| 单一个股占比 | ≤ 20% |
| 单一行业占比 | ≤ 35% |
| 前五大重仓合计 | ≤ 60% |
| 现金比例 | 常态 10% – 30% |
| 组合最大回撤容忍 | 提前设定，如 −15% 触发降仓 |

## 六、常见错误

1. 满仓单一股票，把"研究深度"误当成"确定性"；
2. 亏损后不断加仓，把交易变成信仰；
3. 赚钱后自我膨胀，快速放大仓位；
4. 从不记录仓位变化，无法复盘决策质量。

> 仓位管理是唯一能让你在判断错误时依然留在牌桌上的能力。
