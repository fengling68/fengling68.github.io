1. 股市与新手上路

什么是股票

股票是公司发行的所有权凭证。你买入股票，就成为了公司的股东，享有分红权和投票权（普通股）。股价短期由买卖供需决定，长期由公司价值决定。

交易时间详解（按时间段划分）

A 股一天的交易被切分成多个阶段，每个阶段规则不同。新手最容易踩的坑是"9:20 后不能撤单"和"以为午休也能成交"。

时间段阶段规则与说明
9:15–9:20开盘集合竞价（可撤单）可挂单也可撤单。此时的挂单 / 撤单不代表真实成交，常被用来"试盘"或制造假象，参考意义有限。
9:20–9:25开盘集合竞价（不可撤单）可挂单但不能撤单。9:25 按"最大成交量"原则一次性撮合成交，产生开盘价。这段的委托更真实。
9:25–9:30开盘前静默券商接受委托并暂存，但系统不撮合；9:30 连续竞价开始后统一处理。此阶段看不到成交。
9:30–11:30上午连续竞价系统按"价格优先、时间优先"实时逐笔撮合，就是平时看到的实时行情与成交。
11:30–13:00午间休市不交易、不撮合。部分券商支持"预埋单"（休市期间挂单，13:00 自动报送）。
13:00–14:57下午连续竞价同上午。
14:57–15:00收盘集合竞价沪深均适用。按最大成交量撮合成交，产生收盘价；14:57 后不可撤单。
15:00–15:30盘后交易① 大宗交易：大笔买卖协议成交，不冲击盘面；② 科创 / 创业板盘后固定价格交易：按收盘价成交，给没赶上竞价的人补救机会。
集合竞价撮合原则：系统把所有买卖委托按"最大成交量"匹配出一个成交价，再按"价格优先、时间优先"分配。所以集合竞价的"开盘价 / 收盘价"是撮合出来的，不是某笔单子决定的。
成本意识：频繁短线交易会被手续费吞噬利润。一笔"万3 佣金 + 万5 印花税"的来回交易成本约 0.11%，意味着股价不涨 0.2% 你就亏了。

5. 基金与 ETF 品种全景

对大多数散户来说，选对基金往往比选对个股更容易跑赢市场：基金天然分散持仓、由专业团队管理，还能让普通人一键参与某个行业、指数或海外市场的机会。基金不是股票，但属于同一大类"证券投资工具"。

为什么要懂基金

买不起一篮子股票？没时间研究财报？基金用"集合投资"帮你解决。它也是资产配置、定投、避险的重要工具。

  • 主动基金依赖基金经理能力，可能大幅跑赢也可能跑输；选基要看长期业绩、最大回撤、经理稳定性。

6. K 线入门

K 线（蜡烛图）是记录一段时间（日/周/分钟）内开盘价、收盘价、最高价、最低价的图形，是看盘最基础的语言。

单根 K 线结构

  • 实体：开盘价与收盘价之间的矩形。
  • 阳线（红）：收盘价 > 开盘价，A 股习惯用红色表示上涨。
  • 阴线（绿）：收盘价 < 开盘价，A 股习惯用绿色表示下跌。
  • 上影线：实体上方的细线，代表盘中最高价（上方抛压）。
  • 下影线：实体下方的细线，代表盘中最低价（下方支撑）。

11. 支撑与压力

  • 支撑位：股价跌到此处买方增强、止跌反弹的位置（如前低、均线、密集成交区、整数关口）。
  • 压力位：股价涨到此处卖方增强、遇阻回落的位置（如前高、均线、跳空缺口、整数关口）。
  • 相互转化：有效跌破支撑后，该位置变压力；有效突破压力后，该位置变支撑（"跌破变压、突破变撑"）。
  • 趋势线：连接两个及以上低点得上升支撑线；连接高点得下降压力线。线越被验证次数多，越有效。
  • 缺口：跳空高开 / 低开留下的价格空白区。向上跳空常为支撑，向下跳空常为压力；"缺口必补"非绝对，强势行情可不补。

12. 趋势线、通道与扇形线

趋势线是技术分析的"画线基本功"。它把杂乱的波动归纳成一条有方向的线，用来判断趋势是否还在、以及何时可能转折。配合『支撑与压力』一章一起看，效果更好。

怎么画趋势线

  • 上升趋势线连接两个依次抬高的低位（低点2 高于 低点1），并至少被第三个低点确认。
  • 下降趋势线连接两个依次降低的高位（高点2 低于 高点1）。
  • 触点越多、持续时间越长，趋势线越"值钱"（越有效）。

通道线（轨道）

在趋势线基础上，画一条与之平行的线连接另一侧的高点/低点，形成"通道"。价格常在通道上下沿之间运行；触及上沿易回落，触及下沿易反弹。

扇形线（趋势线的递进）

一条趋势线被有效跌破后，连接更早的低点画第二条（更平缓）；再破则画第三条。三条扇形线依次变平缓，往往意味着原趋势衰竭、转折临近——所谓"三破反转"。

13. MACD 指标

MACD（指数平滑异同移动平均线）是趋势型指标，用于判断趋势强弱、转折点与背离，是最常用的指标之一。

三个组成部分

  • DIF（快线）：EMA12 − EMA26，反映短期与中期成本差。
  • DEA（慢线）：DIF 的 9 日平滑均线，信号线。
  • MACD 柱（红绿柱）：(DIF − DEA) × 2，柱体在零轴上下摆动，柱缩短 = 动能减弱。
红柱（DIF>DEA·多头动能） 绿柱（DIF<DEA·空头动能） DIF DEA
图 13-1　MACD：零轴之上为多头区；DIF 上穿 DEA 为金叉（买参考），下穿为死叉（卖参考）

主要用法

信号判断
金叉DIF 上穿 DEA（尤其零轴下方金叉、零轴上方金叉更强）→ 买入参考
死叉DIF 下穿 DEA → 卖出参考
零轴零轴上方 = 多头市场；下方 = 空头市场。零轴上方金叉更可靠

底背离股价创新低，MACD 双线 / 绿柱却抬高 → 下跌衰竭，警惕见底
参数：默认 (12, 26, 9)。MACD 偏中长线，对短线噪音不敏感，适合判断"趋势有没有变"，不适合抓精确拐点。背离是它最有价值的信号。

14. 摆动指标

KDJ（随机指标）是超买超卖型摆动指标，对短线拐点敏感，常与 MACD 搭配（MACD 看趋势、KDJ 找买卖点）。

三条线

  • K 线：快速确认线，敏感。
  • D 线：慢速主干线，较平滑。
  • J 线：方向敏感线，= 3K − 2D，可上穿 100 / 下破 0，最敏感也最容易骗线。
K D J 超买区(>80) 超卖区(<20)
图 14-1　KDJ：进入 80 以上为超买、20 以下为超卖；K 上穿 D 为金叉、下穿为死叉

核心读数（0–100）

区间含义
K、D > 80超买区，高位钝化时股价仍可能继续涨，不宜单凭"超买"就卖
K、D < 20超卖区，低位钝化时股价仍可能继续跌
金叉（K 上穿 D）低位金叉（20 附近）更可靠；高位金叉需谨慎
死叉（K 下穿 D）高位死叉（80 附近）风险大
J 值>100 超买极端；<0 超卖极端，常作预警
钝化陷阱：强势单边行情中 KDJ 会长期停留在超买 / 超卖区（"钝化"），这时若机械反手，易被甩下车或抄在半山腰。KDJ 在震荡市最好用，在单边市需配合趋势指标。

RSI 指标

RSI（相对强弱指标）衡量一段时间内上涨力度与下跌力度的对比，范围 0–100，也是超买超卖型指标。

常用参数与读数

参数特点
RSI6极灵敏，适合超短线
RSI12常用中期
RSI24较平滑，适合中长期

读数含义

  • 70 以上：超买，短期过热，注意回落风险（非立刻卖，结合趋势）。
  • 30 以下：超卖，短期过冷，关注反弹机会。
  • 50 中轴：多空分水岭；RSI 在 50 上方偏强，下方偏弱。
  • 背离：股价新高而 RSI 不新高（顶背离）；股价新低而 RSI 不新低（底背离）——转势预警。
RSI 与 KDJ 都是摆动指标，二者择一即可，不必同时堆叠。RSI 比 KDJ 更平滑、更少假信号，适合判断"涨过头 / 跌过头"。

15. BOLL 布林带

BOLL（布林带）由中轨（20 日均线）+ 上下轨（中轨 ±2 倍标准差）构成，像一个"通道"，反映股价的波动区间。

三条轨道

  • 中轨（MID）：MA20，趋势方向。
  • 上轨（UPPER）：中轨 + 2σ，短期压力。
  • 下轨（LOWER）：中轨 − 2σ，短期支撑。
上轨（压力） 中轨（MA20） 下轨（支撑） 价格
图 15-1　BOLL 通道：价格触及下轨易反弹、触及上轨易回落；通道开口=波动加大，收口=面临变盘

用法

情形含义
价格触下轨可能获得支撑反弹（震荡市有效）
价格触上轨可能遇压回落
开口放大波动率加大，趋势可能启动（突破上轨 = 强势，跌破下轨 = 弱势）
收口收窄波动率变小，面临方向选择（"横久必突"）
中轨方向中轨向上 = 偏多；向下 = 偏空
布林带口诀："下轨买、上轨卖"只在震荡市好用；趋势行情中价格会贴着上轨（强势）或下轨（弱势）运行，此时"触轨就反"会亏钱。看轨的方向比看位置更重要。

16. 其他常用指标

BIAS 乖离率

衡量股价偏离均线的程度：BIAS = (收盘价 − MA) / MA × 100%。正乖离过大（股价远高于均线）有回落需求；负乖离过大有反弹需求。常用 6 日 / 12 日乖离。

WR 威廉指标

范围 0–100，80 以上为超卖、20 以下为超买（与 KDJ/RSI 读数方向相反，注意区分）。反映"收盘价在最近 N 日高低区间的位置"。

OBV 能量潮

以成交量累加：上涨日加量、下跌日减量。OBV 上升说明资金持续流入，与价格同向为健康，背离警示转势。

筹码分布（CYQ）

显示不同价位上的持仓成本堆积，像"山峰"。密集峰是支撑 / 压力区；股价上方无套牢峰（"真空区"）利于上行；下方获利盘过多需防兑现。

振幅 / 换手率

  • 换手率 = 成交股数 / 流通股本。高换手（如 >10%）说明交投活跃、分歧大；低位高换手可能是吸筹，高位高换手警惕出货。
  • 振幅 = (最高 − 最低) / 昨收，反映当日波动激烈程度。
指标组合建议：趋势方向用 均线 + MACD；买卖时机用 KDJ / RSI + 量能；波动区间用 BOLL；资金态度用 成交量 + OBV + 换手。指标互相印证，比单看一个更稳。

17. 量价关系

价格是结果，成交量是背后的"资金投票"。理解量价，是看懂一切技术图形的底层逻辑。

组合位置解读
价升量增上升初期 / 途中健康上涨，可持股
价升量缩上升途中跟风不足，警惕回调
价跌量增高位出货 / 恐慌，风险大
价跌量缩下跌末端抛压衰竭，可能见底
低位放量长期下跌后可能有资金建仓，关注
高位放量滞涨大涨后经典见顶信号，务必警惕
铁律：任何技术形态，若没有量能配合，可信度都打折。"放量突破"比"缩量突破"可靠得多。

19. 财务报表与估值体系

技术面看"价格走势"，基本面看"公司本身值不值"。读懂财报和估值，才能判断一只股票是便宜还是贵、是在赚钱还是烧钱。

19.1 公司赚钱能力（利润表核心）

指标含义 / 公式怎么看
营业收入卖产品/服务收到的钱（营收）看规模与增速，持续增长才好
营业利润营收 − 成本 − 费用 − 税费主营真实盈利能力
净利润最终赚到的利润（归母净利更常用）股东真正分到口径下的盈利
毛利率(营收 − 营业成本) / 营收越高说明产品越"值钱/有壁垒"
净利率净利润 / 营收扣除所有费用后的真实赚钱效率
经营性现金流主营业务实打实收到的现金利润"含金量"，比净利润更难造假
利润 ≠ 现金：账面盈利但经营现金流长期为负，可能是"纸面富贵"（货卖了没收回钱）。看利润表一定要对照现金流量表。

19.2 关键财务指标（ROE 等）

指标公式意义
ROE 净资产收益率净利润 / 净资产股东每投 1 元能赚多少，巴菲特最看重；长期 >15% 较优
ROA 总资产收益率净利润 / 总资产衡量全部资产赚钱效率，重资产行业参考
资产负债率总负债 / 总资产越低越稳健；过高有偿债风险（金融业天然高）
营收/净利增速本期 vs 去年同期成长性，高估值需要高增长支撑
自由现金流经营现金流 − 资本开支公司真正能自由支配的"闲钱"

19.3 估值指标大全（市盈率家族等）

指标公式怎么用
PE 市盈率（静态）股价 / 上年每股收益用过去业绩估，反应慢
PE 市盈率（TTM）股价 / 最近 12 月每股收益滚动口径，最常用
PE 市盈率（动态）股价 / 预测本年每股收益含预期，波动大
PEGPE / 净利润增速(%)PEG < 1 常被视作"增长匹配、相对便宜"
PB 市净率股价 / 每股净资产适合银行、地产等重资产/破净股
PS 市销率总市值 / 营业收入适合暂未盈利的高成长公司
股息率每股分红 / 股价价值/防御股参考，越高越"收租"
EV/EBITDA企业价值 / 息税折旧前利润跨资本结构比较更公平
PE 不是越低越好：周期股（如钢铁、航运）利润高点 PE 反而低，是"周期顶部陷阱"；困境反转股 PE 高甚至为负，不代表不能买。估值必须同行业横向比 + 历史纵向比。

财报深挖：三大报表 + 杜邦分析

三大报表速记

  • 利润表：一段时间赚了多少（营收−成本−费用=净利润）。看"盈利能力"。
  • 资产负债表：某时点家底（资产 = 负债 + 所有者权益）。看"偿债与安全"。
  • 现金流量表：钱怎么进出的（经营/投资/筹资三大活动）。看"真金白银"。
黄金法则：利润可以粉饰，现金流很难造假。经营现金流长期为正且覆盖净利润，才是"赚到真钱"。

20. 公司事件与公告

公司分红、送股后，每股价值下降，股价必须同步下调，否则老股东凭空多赚——这个"下调"就是除权 / 除息。除权除息日当天股价会"看起来暴跌"，其实是会计调整，你的总资产没变。

关键日期

  • 股权登记日：这天收盘后仍持有股票，才有权参与本次分红送转。
  • 除权除息日（XD / XR / DR）：股价正式下调的日子，名称前出现对应字母（见第 1 章）。当天买入不享本次权益。
  • 派息日 / 送转股上市日：现金到账、送转股份可流通的日子。

参考价计算公式（重点）

情形除权（息）参考价公式说明
仅现金分红（除息）前收盘价 − 每股现金红利最单纯的"除息"，股价减去分红额
仅送股 / 转增（除权）前收盘价 ÷ (1 + 送转股比例)10 送 3 → 比例 0.3，股价约降为 1 / 1.3
仅配股(前收盘价 + 配股价 × 配股比例) ÷ (1 + 配股比例)配股要花钱认购，不操作会被除权"白亏"
混合（分红 + 送转 + 配股）(前收盘价 − 红利 + 配股价×配股比例) ÷ (1 + 送转比例 + 配股比例)最通用公式，交易所据此算"参考价"

复权

除权会在 K 线上留下"向下的缺口"，让长期走势看着断裂。软件用复权把它补齐：

  • 前复权：以当前价为基准，把历史价格向下调整，使 K 线连续——新手看这个最直观。
  • 后复权：以历史某日为基准，把之后价格向上累加，反映"若一直持有、分红再投"的真实收益。
  • 不复权：显示真实成交价，会有缺口，适合看除权日当天的真实盘面。
配股是"权利"也是"陷阱"：配股要你再掏钱买，不买就会因除权而亏损（市值缩水）。公布配股后，要么参与配股，要么在股权登记日前卖出，别"忘了管"。

21. 分红派息与股息率

买股票赚两笔钱：一笔是价差（低买高卖），一笔是分红（公司把利润返给股东）。理解分红，是理解"价值投资"和"红利策略"的起点。

两种分红方式

方式给到你什么股价会怎样
现金分红直接发现金到账户除息后股价下调（总权益不变）
送股 / 转增多给股票（股本变大）除权后股价按比下调

关于"股权登记日、除权除息日、派息日"以及"为什么除权后股价会掉"，详见『公司事件与公告』一章，这里从投资者回报角度继续。

股息率：衡量"分红厚不厚"

股息率 = 每股年度分红 ÷ 当前股价 × 100%。例如股价 10 元、每股年分红 0.5 元，股息率就是 5%。股价越低、分红越高，股息率越高。

红利策略为什么有效

  • 持续高股息的公司，往往现金流好、盈利稳定，是"看得见的回报"。
  • 熊市里，分红能部分对冲股价下跌，提供"安全垫"。
  • 缺点：高股息也可能是"价值陷阱"（公司走下坡路、被迫高分红）。
图 21-1　分红流程时间轴：在股权登记日持有才能拿到分红

回购 vs 分红

回购是公司在二级市场买回自己的股票并注销，能提升每股价值、托底股价；分红是直接发现金。两者都是回馈股东，但回购对股价的支撑更"主动"。

看分红别只看"高"：关注分红的连续性、分红率（分红占净利润比例）、和盈利质量。一次性高分红、或靠借钱分红的公司要警惕。

23. 缺口理论

缺口（跳空）指相邻两根 K 线之间出现一段"没有成交"的价格空白——当日最低价高于前一日最高价（向上缺口），或最高价低于前一日最低价（向下缺口）。缺口往往代表情绪的集中爆发。

四类缺口

类型出现位置含义操作提示
普通缺口横盘震荡区随机、很快回补意义不大，别过度解读
突破缺口横盘末 / 关键位突破趋势启动信号不回补=强势，可顺势
中继缺口趋势中途行情加速，非终点持有，趋势延续
衰竭缺口趋势末端最后一冲，随后反转警惕见顶/底，准备减仓
图 23-1　同一段上升趋势中的三类缺口：突破→中继→衰竭。红色虚线框即"跳空"价格空白区（无成交），末端反转（绿）。普通缺口多在横盘且很快回补，未单独画出。

岛形反转

一段趋势末端，先出现一个跳空缺口，不久后反向再来一个跳空缺口，中间的价格像一座"孤岛"被两个缺口隔开——这是强烈的趋势反转信号（常配合衰竭缺口）。

图 23-2　岛形反转：上涨末端先"向上跳空"进入孤岛，随后反向"向下跳空"离开孤岛，中间高价区被两个缺口夹成孤岛，是强烈反转信号。
缺口会"回补"（价格 later 回到缺口区间内）。一般：普通缺口必补，突破缺口可不补，衰竭缺口补后确认反转。别把任何缺口都当"必补"去逆势操作。

24. 形态进阶：楔形·矩形·圆弧·岛形

『常见技术形态』一章讲了头肩、双顶底、三角、旗形。这里补全另外四类高频形态，完善你的"图形库"。

楔形（Wedge）

两条同向收敛的趋势线（都向上或都向下），价格波动区间逐渐收窄。与三角形不同，楔形的两条边方向一致。多数楔形是反转形态：上升楔形看跌、下降楔形看涨。

矩形（箱体 Box）

价格在两条水平线之间上下震荡，多空僵持。矩形多为持续形态：突破上沿看涨、跌破下沿看跌。箱体下沿是支撑、上沿是压力。

圆弧底 / 圆弧顶

价格缓慢地"磨"出一个圆弧，是慢转折信号。圆弧底（碗形）常见于长期筑底，一旦放量突破弧线右侧，往往开启主升；圆弧顶反之。

岛形反转

见『缺口理论』一章：由两个反向缺口夹出的"孤岛"，是强烈的反转信号，常出现在趋势末端。

形态越大（构筑时间越长）、成交量配合越到位，突破后的空间往往越大。所有形态都要等"突破 + 确认"再动手，提前埋伏容易在时间成本上吃亏。

25. 三大经典理论

道氏理论由查尔斯·道创立，是技术分析的理论源头。它不预测点位，而是判断"趋势状态"，核心回答一个问题：现在到底是在上涨、下跌，还是震荡？

三大公理（假设）

  • 市场指数包容一切：价格已反映所有已知和预期的信息（经济、政策、情绪、资金）。
  • 价格沿趋势运行：趋势一旦形成，会延续直到出现明确的反转信号。
  • 历史会重演：人性不变，相似的图形在不同时间反复出现（但不是简单复制）。

三种趋势

级别时长特征
主要趋势（牛/熊）数月～数年决定大方向，最值得顺势
次级趋势（中级调整）数周～数月对主要趋势的回撤（牛市中的回调、熊市中的反弹）
短暂趋势（日常波动）数日～数周噪音多，容易骗线，短线才关心

牛熊三阶段

  • 牛市：① 怀疑期（底部放量、无人相信）→ ② 确认期（突破关键阻力、右侧确立）→ ③ 狂热期（全民炒股、估值泡沫）。
  • 熊市：① 出货期（高位滞涨、放量下跌）→ ② 恐慌期（加速杀跌）→ ③ 绝望期（阴跌筑底、缩量见底）。
成交量验证：道氏强调"价涨量增、价跌量缩"才是健康趋势；上涨缩量或下跌放量都预示趋势可能衰竭。
局限：道氏偏"事后确认"，信号滞后，无法直接给出买卖点，更适合判断大环境而非精确抄底逃顶。

波浪理论入门

艾略特波浪理论认为，市场遵循"五浪上升 + 三浪调整"的循环，且大浪套小浪（分形结构）。它是预测性工具，也最容易被主观数错。

八浪结构

图 25-1　八浪循环：1-2-3-4-5 上升（红），A-B-C 调整（绿）

各浪要点

  • 第 1 浪：熊末第一波反弹，常被误认为反弹，量能温和。
  • 第 2 浪：回撤但不破第 1 浪起点，缩量。
  • 第 3 浪：最凌厉、最长的一浪，放量突破，往往最具赚钱效应。
  • 第 5 浪：末升浪，常出现量价背离、指标顶背离，警惕见顶。
  • A-B-C 调整：三浪下跌，C 浪常最凶；完成后重新开始新的五浪。

斐波那契比率

浪与浪之间的幅度常用黄金比例度量：2 浪回撤 1 浪的 0.382/0.5/0.618；3 浪约为 1 浪的 1.618 倍；4 浪回撤 3 浪的 0.382；5 浪约等于 1 浪高度或 0.618×(1+3) 浪高度。这套比例用于预判目标位与支撑位。

难点：同一走势可"数"出多种浪型，主观性强。建议只把它当"大概率框架"，配合趋势线与指标，不孤注一掷。

缠论基础：分型、笔、线段

缠论是一套自成体系的买卖点理论，核心是用几何结构定义走势，不依赖指标。入门先掌握三个基本构件。

① 分型

由相邻三根 K 线构成：顶分型＝中间 K 线最高、两侧渐低；底分型＝中间 K 线最低、两侧渐高。分型是走势转折的最小信号。

② 笔

两个相邻同性质分型之间、且越过中间至少一根 K 线的连线，称为一笔。向上笔连接底分型→顶分型；向下笔连接顶分型→底分型。笔是"有方向的线段"。

③ 线段

至少由三笔组成、且首尾方向一致的连续结构，代表一段可控的走势。线段被反向线段破坏即确认原趋势结束。

图 25-1　底分型→向上笔→顶分型→向下笔，构成最基础的笔走势

中枢与背驰（进阶）

  • 中枢：三段重叠的价格区间，是买卖双方反复争夺的"震荡箱"，代表趋势的喘息。
  • 背驰：股价创新高（或新低）但力度（如 MACD 红柱面积、成交量）不增反减，提示趋势即将反转——这是缠论最核心的买卖点依据。
学习建议：缠论门槛高、定义严格（笔段有苛刻包含关系处理），新手先搞懂分型与笔，再逐步深入中枢与背驰，别一上来就追求精确买卖点。

26. 主力与筹码分析

筹码分布（成本分布）用"不同价格上堆积的持仓量"画出筹码峰，帮你看清"大家的成本在哪、谁在盈利、谁在套牢"。

关键概念

  • 筹码峰：成交量密集的价格区，即大多数人的持仓成本区。
  • 单峰 / 多峰：单峰＝成本高度集中（易拉升）；多峰＝筹码分散（上有套牢、下有获利，压力大）。
  • 获利盘 / 套牢盘：当前价上方为套牢盘，下方为获利盘。
  • 集中度：数值越低，筹码越集中，主力控盘度越高。
图 26-1　当前价（蓝线）下方为获利筹码（红），上方为套牢筹码（绿）

实战读法

  • 低位单峰密集 + 放量突破：主力吸筹完毕、成本一致，是强启动信号。
  • 高位单峰密集 + 放量滞涨：筹码在高位换手给散户，警惕派发。
  • 双峰对峙：上峰套牢、下峰获利，股价常在区间震荡消化。

主力行为全解：吸筹·洗盘·拉升·出货

所谓"主力"是资金体量足以影响股价的机构或大户。理解其运作四阶段，能帮你站在大概率一边。

阶段价格特征量能特征散户感受
吸筹低位横盘、小阴小阳温和放量、间歇放量"这票不动，垃圾"
洗盘小幅打压、震仓缩量下跌"是不是要跌了？"割肉
拉升放量突破、连阳持续放量"后悔卖早了"追高

识别口诀：低位"利空不跌、缩量止跌"多在吸筹；高位"利好不涨、放量长上影"多在高出货。永远别在高位放量滞涨时恋战。

27. 龙虎榜与异动榜解读

龙虎榜是交易所公布的"当日异常交易席位成交明细"，是观察主力资金动向的公开窗口。

触发条件（A 股常见）说明
日涨跌幅偏离 / 达到 ±7%（主板）、±15%（双创）价格异动上榜
日换手率达到 20%交投极度活跃上榜
日振幅达到 15%剧烈波动上榜
无涨跌幅限制新股首日等特殊情形上榜

看什么

  • 买方 vs 卖方力量：净买入为正、买方席位强，偏多。
  • 席位性质：机构专用（中线逻辑）、知名游资（短线情绪）、沪 / 深股通（外资）、"拉萨天团"（散户集中，常被视为反向指标）。
  • 异动榜 / 涨幅榜 / 跌幅榜：观察当日资金偏好与情绪冷热。
注意：龙虎榜是 T+1 盘后公布，具有滞后性；上榜不等于明天必涨，别盲目跟风。结合题材持续性与大盘环境综合判断。

28. 短线题材炒作

涨停板类型

  • 一字板：开盘即涨停，买不进，最强（利好/主线龙头）。
  • T 字板：开盘涨停后被砸开又回封，分歧转一致。
  • 换手板：全天充分成交后封板，更健康、可持续。

打板术语

扫板（直接吃涨停价挂单）、排板（在涨停价排队等成交）、板上确认（封死后再介入）。风险极高，适合有纪律的短线客。

短线情绪周期

图 28-1　情绪周期：冰点→回暖→高潮→退潮→再冰点，循环往复
  • 冰点：连板高度压缩、亏钱效应弥漫，是最佳试错买点。
  • 回暖：出现先锋涨停、高度打开。
  • 高潮：普涨、百股涨停，应"卖在一致"。
  • 退潮：高位杀跌、天地板，必须空仓避险。
重要风险提示：打板与情绪博弈是 A 股最难、最易亏损的模式之一，20% 涨跌幅下天地板可单日亏 30%+，新手慎用，先模拟。

场景驱动下的板块轮动规律

股市很少"齐涨齐跌"，资金会随宏观场景与突发事件在不同板块间轮动。理解"什么环境买什么"，比死记代码更重要。下面按常见场景列出受益板块与逻辑：

通胀上行 / 商品涨价黄金、有色（铜铝）、油气、煤炭、农产品（玉米大豆）涨价直接抬升商品价格；资源股业绩与商品价格强相关，通胀利好实物资产

经济衰退 / 避险黄金、国债、公用事业、医药避险推升黄金；防御板块需求刚性、业绩波动小，资金"抱团"避险
战争 / 地缘冲突油气、黄金、军工、粮食（玉米大豆）、航运冲突扰动供给→油价粮价涨；军工订单预期升温；避险买黄金

29. 技术分析实战

单一指标容易骗线，高手讲究"多维度相互验证"。

多周期共振

看大周期定方向（周线/日线判趋势），小周期找买点（60 分/15 分找入场）。大周期向上、小周期回踩企稳，才是高胜率买点；逆大周期抄底常失败。

经典指标组合

  • 趋势：均线多头排列 + 股价在年线（250）上方 = 牛市格局。
  • 动量：MACD 金叉 + 零轴上方 + 红柱放大 = 主升确认。
  • 量能：突破必须放量，缩量突破多为假突破。
  • 超买：KDJ/RSI 高位钝化时，不急于卖，等背离确认。
假突破识别：无量冲过前高、当日长上影、次日跌回区间内，多为诱多；真突破常伴随跳空缺口与持续放量。
买点框架：大周期向上 + 回踩重要均线/支撑 + 放量阳线启动 + 指标金叉 = 四类信号共振时出手，胜率与赔率最佳。

30. 资金面与衍生工具

除个股技术面与基本面，还要懂"钱从哪来、有哪些工具"。这些是 A 股生态的重要组成。

30.1 市场资金构成

资金类别说明看什么
北向资金外资通过沪/深股通买卖 A 股（"聪明钱"参考）每日净买入额、持股变动
融资融券（两融）融资=借钱买股（杠杆看多）；融券=借券卖出（看空）融资余额升=情绪升温
公募 / 私募 / 险资机构主力，调仓影响板块基金重仓、发行冷热
龙虎榜异动股（涨停/跌停/大幅波动）的买卖席位披露知名游资/机构进出
北向暂停披露口径变化：近年北向资金实时数据披露方式有过调整，看盘时以交易软件当日展示为准，不要盲信过时口径。

30.2 常见衍生 / 稳健工具

工具特点适合谁
ETF（交易型指数基金）一篮子股票、费率低、透明，跟踪指数不想选个股、想布局板块/宽基的人
指数 / 主动基金定投分批买入摊薄成本，纪律化上班族、长期储蓄型投资者
可转债可转股的债券，下有债底、上跟正股，"进可攻退可守"稳健偏保守、想参与权益的人
新股申购（打新）市值配售、中签缴款，历史多数有溢价有持仓市值的账户（需开通权限）

30.3 分红与税

  • 现金分红：公司把利润直接发钱，除息后股价下调（总市值不变）。
  • 红利税：持股 >1 年免征；1 个月–1 年按 10%；≤1 个月按 20%（以卖出时持股期限算）。
  • 送转股：送股/转增股本，除权后股价下调、股数增加，注意"填权/贴权"。
工具选择逻辑：看不懂个股 → 用 ETF/基金；怕波动又想参与 → 可转债；有耐心长期 → 定投宽基；只做个股 → 必须把技术 + 基本面 + 资金面三件套结合。

31. 指数基金与 ETF 定投实战

ETF 种类

  • 宽基 ETF：沪深300、中证500、创业板指——分散个股风险，适合大多数人的底仓。
  • 行业/主题 ETF：券商、医药、半导体、新能源——押注赛道贝塔。
  • 跨境 ETF：纳指、港股——一键配置海外。

定投微笑曲线

定期定额买入：市场下跌时同样的钱买到更多份额（摊低成本的"左侧"），市场回升后盈利。定投的核心是"用时间平滑波动"，适合没时间盯盘的上班族。

进阶技巧

  • 估值定投：低估（如 PE 历史分位 < 30%）多投，高估少投或止盈。
  • 止盈策略：目标收益率止盈（如 +30%）、估值分位止盈（如 > 80%）、或回撤止盈。
定投纪律：坚持不择时、不间断，最忌"一跌就停、一涨就追"。长期（3–5 年以上）才能体现复利与摊平效果。

32. 可转债

可转债"下有债底、上不封顶"，是进可攻退可守的品种，但条款复杂。

核心公式

  • 转股价值 = 100 ÷ 转股价 × 正股价（一张债能换成的股票市值）。
  • 转股溢价率 =（转债价 − 转股价值）÷ 转股价值 ×100%（溢价越低越"股性"强）。
图 32-1　可转债价格由"债底"和"转股期权"两部分构成

关键条款

  • 强赎：正股连续 N 日高于转股价 130%，公司可强制赎回——持债人须及时卖出或转股，否则被低价赎回亏损。
  • 下修：正股大跌、转债价低迷时，公司下调转股价，提升转股价值，对转债是利好。
  • 回售：特定条件下持有人可把债按面值+利息卖回公司，是保护条款。
打新：顶格申购新转债，上市首日大多上涨，是近乎无风险的小额福利（具体配售规则以当时监管规定为准）。

33. 期权基础

期权是"在未来以约定价格买卖标的"的权利（非义务），是 A 股少数带杠杆和对冲功能的工具。

基本分类

  • 认购期权（Call）：看涨，有权以行权价买入标的。
  • 认沽期权（Put）：看跌，有权以行权价卖出标的。
  • 买方：付出权利金，亏损有限（最多权利金）、收益潜力大。
  • 卖方：收权利金，收益有限、风险可能很大（义务方）。

价值构成

期权价格 = 内在价值（立即行权能赚的部分）+ 时间价值（对未来的预期）。越临近到期，时间价值衰减越快（"时间损耗"）。

图 33-1　认购期权买方盈亏：横轴标的价格，低于行权价亏权利金（有限），之上随上涨盈利
两大用途：① 杠杆博方向（小资金撬动大波动）；② 保险对冲（持有股票同时买认沽，下跌时期权赚钱抵消股票亏损）。期权复杂度高，务必先模拟交易。

34. 融资融券与杠杆的双刃剑

两融让你"借券商的钱/券"交易，放大收益也放大风险。

融资 vs 融券

融资（做多）融券（做空）
含义借钱买股，涨了还钱赚差价借券卖出，跌了低价买回归还
适合看多且保证金充足看空（A 股券源少、限制多）
风险下跌会追加保证金，否则强平理论上亏损无上限（涨不停）

强平机制

账户维持担保比例 =（现金+股票+债券）÷ 负债。低于警戒线（如 150%）需补钱，低于平仓线（如 130%）券商可强制卖出。杠杆会在暴跌中"加速出局"。

新手警告：杠杆是专业玩家的工具。满仓融资遇黑天鹅，可能一天内被强平、本金归零。普通投资者尽量不用或极低杠杆。

35. 宏观与行业基本面

选股先选行业。好行业出牛股的概率远大于差行业。

产业链位置

  • 上游：原料/资源（矿、化工、半导体材料），价格周期性强。
  • 中游：制造/零部件，受上下游两头挤压，看规模与技术。
  • 下游：品牌/渠道/终端，贴近消费者，看品牌与定价权。

竞争格局

用 CRn（前 n 家市占率）判断集中度：寡头（CR5>60%）格局稳定、龙头吃香；分散行业价格战激烈。

景气与政策

  • 景气度：订单、产能利用率、价格（如锂价、面板价）是先行指标。
  • 政策：补贴、集采、碳中和、国产化替代——A 股政策敏感度极高。
研究框架：行业空间（天花板）→ 竞争格局（谁最强）→ 景气位置（上行/下行）→ 政策导向 → 落实到具体龙头公司的业绩兑现。

宏观经济指标如何驱动股市

宏观是"水温"，决定市场整体的水位与风格切换。

指标含义对股市一般影响
利率 / 降息资金价格降息→流动性宽裕→利好估值（成长股尤甚）
CPI / PPI通胀 / 工业品价格温和通胀可接受；高通胀→加息预期→承压
PMI制造业荣枯线（50 为界）>50 扩张、经济回暖信号

北向资金：通过沪深港通流入的外资，常被视为"聪明钱"风向标，单日大幅净流入/流出会引发关注，但别盲目跟随，它也会犯错。

36. 价值与成长投资风格

价值投资买的是"好公司 + 好价格"，赚企业成长和估值修复的钱，与短线博弈是两套逻辑。

四大护城河

  • 无形资产：品牌（茅台）、专利、牌照（特许经营权）。
  • 网络效应：用户越多越值钱（社交、平台）。
  • 成本优势：规模、区位、工艺带来的低成本。
  • 转换成本：换供应商太麻烦/太贵（企业软件、银行）。

安全边际

用"内在价值"打折的价格买入，留出犯错空间。内在价值常用自由现金流折现（DCF）估算：把公司未来每年的自由现金流，按合理贴现率折算成今天的价值，再除以股本得每股价值。

能力圈：只投自己真懂的生意。看不懂的赛道，再热也不碰——这是巴菲特反复强调的纪律。
适用场景：价值投资适合长期资金、能承受波动的投资者；它需要耐心持有数年，而非几天。典型指标：低 PE/PB、高 ROE、稳定分红、低负债。

成长股投资：赛道、PEG 与景气度

成长股赚的是"业绩高速增长"的钱，愿意为未来买单，估值通常不便宜。

选股三要素

  • 赛道空间：行业天花板高（如新能源车、AI、创新药），渗透率处于早期。
  • PEG 指标：PEG = PE ÷ 净利润增速。PEG < 1 表示"增速能消化估值"，更具性价比。
  • 景气度：行业处于上行周期（订单饱满、价格上涨、政策扶持），业绩兑现概率高。

渗透率 S 曲线

新技术从 0% 到普及呈 S 形：0–10% 概念期（炒作）、10–40% 爆发期（最佳利润区）、40% 以上成熟饱和（杀估值）。投资要在"爆发前夜"介入。

戴维斯双击 / 双杀：业绩与估值同向变动。双击＝盈利↑+估值↑（股价暴涨）；双杀＝盈利↓+估值↓（股价暴跌）。成长股最怕"增速不及预期"引发双杀。

37. 选股实操流程

把"怎么选出一只能买的股票"拆成可执行的六步，从大环境到买点再到纪律，一步步来。

37.1 流程概览

38. 自上而下与自下而上选股体系

面对 5000 多只 A 股，怎么下手？两套主流框架帮你建立"选股坐标系"。与『选股实操流程』一章的六步法配合使用。

自上而下（先赛道，后个股）

从宏观大环境出发，层层收窄到具体公司：宏观 → 行业 / 板块 → 个股。先判断当下什么风格、什么行业景气向上，再在好行业里挑龙头。

步骤问自己
① 宏观定调经济周期、利率、政策风向偏向哪类资产？
② 选行业哪个行业景气向上、有政策 / 技术催化？
③ 选个股行业内谁是最强龙头 / 弹性最大标的？

自下而上（先个股，后验证）

反过来，先在全市场用财务质地 + 护城河筛出一批"好公司"，再回头看它们所处的行业是否景气、估值是否合理。价值投资者更偏这套。

两者如何结合

  • 用自上而下锁定"风口"（提高胜率与弹性）。
  • 用自下而上确保买的是"好公司"（避免风口里的垃圾股）。
  • 交集 = 既在景气赛道、自身质地又过硬的标的，优先进入核心股票池。

40. 北向资金与机构持仓选股

散户之外，市场上有一批"聪明钱"——北向资金（外资）和各类机构。跟踪它们的动向，是很多选股体系的加分项。

北向资金（沪深股通）

  • 指通过香港通道净买入 A 股的外资，被称为"聪明钱"，因其研究能力强、偏向长期。
  • 看两个维度：整体净流入/流出（判断外资风险偏好）+ 行业/个股增持方向（找具体标的）。

41. 仓位管理与止损纪律

"买什么"决定收益，"怎么管钱"决定你能否活到赚钱那天。仓位与止损是散户最该先练好的功课。

41.1 金字塔加仓（正金字塔）

首次建仓最大，越涨加得越少——成本始终低于市价，且风险递减。

首次建仓 50%
回踩加仓 30%
突破再加 20%
图 41-1　正金字塔加仓：底宽顶窄，上涨过程中仓位是"递减追加"
禁止倒金字塔：越涨买得越多（顶宽底窄）会在高位堆满仓位，一回调就巨亏，是散户常见死法。

41.2 止损方法

方法怎么设适用
固定比例止损买入价下方 5%–8% 机械止损短线、纪律差的新手首选
支撑位止损跌破关键均线/前低/趋势线离场技术交易者
移动止损（跟踪）随价格上涨上移止损线，保住利润趋势/中线持仓
时间止损买入后 N 日不涨反弱，先退出事件/题材驱动

41.3 仓位口诀

  • 单只上限：不超过总资金的 30%，避免"一失足满盘皆输"。
  • 行情定总仓：牛市可 60%–80%，震荡 30%–50%，熊市 ≤ 20% 或空仓。
  • 分仓：不要一次满仓，留有余地才能"跌了敢加、错了能撤"。
  • 盈利才加仓：亏损股不补仓摊平，那只会把小错变大错。
一句话：先想"最多亏多少"再想"能赚多少"；止损线提前画好，盘中只执行、不纠结。活得久比赚得快重要。

42. 复盘与计划

每日复盘四步

  1. 看大盘：指数涨跌、量能、北向、涨跌家数，判断市场温度。
  2. 看板块：领涨/领跌板块、资金流向、是否有持续性主线。
  3. 看个股：持仓股走势是否符合预期，自选股有无买点信号。
  4. 做计划：写下明日"买什么、什么价、买多少、错了怎么办"。

交易日志

每笔交易记录：买入理由、仓位、止损位、卖出原因、情绪状态。定期回看，找出自己的"亏钱模式"——大多数人反复犯同一类错误。

周/月总结：统计胜率、盈亏比、最大回撤；哪类模式赚钱、哪类亏钱。用数据而非记忆迭代自己的交易系统。

43. 交易心理与概率思维

炒股最终拼的是认知与心态。技术易学，人性难改。

常见认知偏差

  • 锚定效应：死记买入价，亏了不肯割（"回本就卖"），被成本绑架。
  • 确认偏误：只信看涨的理由，忽略反面证据。
  • 损失厌恶：亏 100 的痛苦 > 赚 100 的快乐，导致小赚即跑、大亏死扛。
  • 追涨杀跌：被情绪驱动在高位接盘、低位割肉。

概率与期望值

交易不是"对错"，而是"期望值"：EV = 胜率×平均盈利 − 败率×平均亏损。只要 EV 为正，长期坚持必赢；单次盈亏不重要。

凯利公式（参考）：仓位比例 f =（胜率×赔率 − 败率）÷ 赔率。它告诉你"该下多大注"，避免一把梭与过度保守。实战常用"半凯利"更稳健。
纪律优先：提前写好买卖计划并机械执行，比盘中"感觉"可靠得多。情绪上头时，先关软件冷静。

44. 欧奈尔 CANSLIM 强势股选股法

威廉·欧奈尔（William O'Neil）复盘数十年美国牛股，提炼出 CANSLIM 七因子模型：它不预测底，而是"买已经启动的强势股"，在大盘向上时追随领涨龙头。该体系尤其适合成长股牛市与题材主升浪。

七因子速查

字母含义实战看点
CCurrent 当季盈利当季 EPS 同比加速 ≥25%，且营收同步增长
AAnnual 年度盈利近 3 年净利润复合增速高，ROE 优秀
NNew 新事物新产品 / 新管理层 / 股价新高 / 行业新逻辑
SSupply 流通盘流通盘适中、供给有限，易被资金推动
LLeader 龙头相对强弱 RS 居前，绝不买弱势跟跌股
IInstitutional 机构有优质机构增持，但非过度抱团
MMarket 大盘大盘处于上升趋势时才重仓，M 定仓位

杯柄形态与买点

强势股启动前常走出"杯柄形态"：先深度回调形成杯身（U 形），再横盘小幅回落形成杯柄，最后放量突破杯柄上沿即为买点。

图 44-1　杯柄形态：放量突破杯柄上沿为标准的右侧买点，止损设于杯柄下方

卖出与止损纪律

  • 止损：买入后跌破买点 7%–8% 坚决止损，不摊平。
  • 止盈：主升浪中让利润奔跑，跌破 10 周 / 50 日线或放量长阴离场。
  • 大盘风控：M（大盘）转弱、放量破位时整体降仓。
核心口诀：买最强的龙头，在大盘向上时买，破位就走——不猜顶、不抄底弱势股。

45. 趋势跟踪交易系统

"趋势是你的朋友"。趋势跟踪不预测拐点，而是识别已发生的趋势并顺势持有，靠少数大波段盈利覆盖多次小止损。它适合均线、通道、突破类策略，是量化与主观交易共用的底层逻辑。

均线趋势系统

  • 多头排列（短 > 中 > 长）持有，价格跌破关键均线减仓。
  • 经典参数：MA20 判短期、MA60 判中期、MA120 / 250 判牛熊。
  • 线上持有、线下观望，规则简单但需忍受回撤。

通道突破（唐奇安通道）

取 N 日最高价与最低价构成通道，价格向上突破 N 日高点买入，跌破 N 日低点卖出。海龟训练班用 20 日突破入场、10 日突破离场。

海龟法则要点

  • 入场：55 日最高点突破建仓。
  • 头寸：用 ATR（真实波幅）定仓位，波动大则少买，控制单笔风险 ≤1%–2%。
  • 止损：2ATR 反向止损；盈利后移动止损（如吊灯止损）保护利润。

低胜率高赔率的本质

46. 量价背离与顶底背驰

背离是价格与动能不一致的转折预警：价格还在冲高（或探低），但背后的量能或技术指标已先一步走弱 / 走强，预示原有趋势力竭。

顶背离（多头力竭）

价格创新高，但 MACD / RSI / 成交量 未同步创新高，甚至走低。常见于上涨末端，是减仓信号。

底背离（空头力竭）

价格创新低，但指标拒绝新低、率先回升。常见于下跌末端，是逢低布局信号。

量价背离的典型形态

形态含义
价升量缩上涨缺资金跟进，动能衰减，警惕回落
价跌量增恐慌抛售 / 出货，下跌或有惯性
地量见地价极度缩量后抛压枯竭，常临近阶段底部
天量见天价巨量换手后上涨乏力，易见阶段顶
陷阱：背离会"多次背离才转折"，不可一出现就逆势操作；必须等趋势线破位 / 放量大反转 K 线确认后再动手。

47. 多周期共振分析

看日线要涨、看周线却在下山——周期冲突最让人纠结。多周期分析就是给趋势"定层级"，让你知道该顺哪个、防哪个。

周期层级与分工

周期角色回答的问题
月线 / 周线定方向（大趋势）现在是牛是熊、主升还是主跌？
日线定波段这一波回调还是反转？
60 分钟 / 分时找买卖点具体哪天哪点进场 / 出场？

共振与冲突

  • 多周期共振大、中、小周期方向一致 → 信号最强、胜率最高，值得重仓跟随。
  • 周期冲突小周期逆大周期（如周线涨、日线跌）→ 多半是"回调/反弹"，不逆大趋势做反向单。
  • 顺大做小：大周期向上时，只在小周期回踩企稳时买；大周期向下时，反弹是减仓机会。

实操口诀：周线看方向、日线看结构、分时看切入点。把止损放在大周期趋势线被破的位置，才能既跟上趋势又不至于在小波动里被洗出去。

48. 市场情绪指标与恐贪周期

价格由资金驱动，资金由情绪驱动。读懂情绪，能在狂热时清醒、在绝望时贪婪。情绪指标是技术面之外的重要"温度计"（与第 28 章短线题材互相印证）。

常用情绪指标

  • 涨跌家数 / 涨停跌停比：普涨普跌的广度信号。
  • 换手率与量能：放量亢奋 vs 缩量冰点。
  • 连板高度与题材持续性：短线情绪风向标。
  • 融资余额 / 北向资金：杠杆与外资的风险偏好。
  • 恐贪指数（Fear & Greed）：综合波动率、动量、避险需求等。

49. 财报季博弈

财报披露窗口是基本面驱动的集中博弈期：业绩超预期往往催化主升，不及预期的"暴雷"则引发踩踏。读懂时间线与公告语言，能在不确定性中找确定性。

披露时间线

报告披露节点关键看点
一季报4 月 30 日前全年开局、春节后景气
中报8 月 31 日前半年经营、半年分红
三季报10 月 31 日前全年指引验证

超预期 vs 低于预期

  • Beats（超预期）：营收 / 净利高于一致预期 + 向好指引，常跳空上涨；关注"是否已被提前炒作"。
  • Misses（低于预期）：不及预期即便仍增长也易杀估值，警惕"利好出尽"。
  • 靴子落地：利空兑现、股价已反映，反而可能见底（利空出尽是利好）。

重点排查：①商誉占比过高（减值风险）；②应收账款畸高、经营现金流为负（纸面利润）；③关联交易与突击营收；④频繁变更会计估计；⑤大股东高位减持。财务真实性优先于成长性。

50. 风险警示与骗局防范

新手十大误区

  • 听"内幕消息"炒股（多为接盘陷阱）。
  • 满仓干、加杠杆（一次黑天鹅清零）。
  • 不设止损，"死扛回本"。
  • 频繁交易、追涨杀跌（被手续费和情绪收割）。
  • 盲目抄底"便宜"股（便宜可能有雷）。
  • 把短期运气当能力，加重仓位。
  • 过度分散或过度集中。
  • 只信技术指标、忽略基本面与仓位。

典型骗局

  • 杀猪盘：社交平台荐股群，诱导高位接盘后跑路。
  • 收费荐股/代客理财：承诺收益的多是违规甚至诈骗。
  • 虚拟盘：假交易软件，入金后无法提现。
  • 场外配资：高杠杆 + 高利息，极易爆仓且不受保护。
铁律：凡是要你"加群、交费、跟单、下载不明 APP 入金"的，一律视为诈骗。正规交易只在持牌券商官方渠道。

风险提示

  • 技术指标是概率工具，不是必胜公式；任何单一信号都可能有假。
  • 散户最大敌人往往是情绪与纪律：追涨杀跌、不止损、满仓赌一只。
  • 设置止损比预测顶部更重要；先想"错了怎么办"，再想"能赚多少"。
  • 不借钱炒股、不杠杆满仓；只用亏得起的闲钱。
  • 技术指标无法预测突发政策、业绩雷、黑天鹅；基本面 + 技术面结合更稳。
  • 本手册仅作知识科普，不构成任何投资建议。投资有风险，决策需谨慎、自负盈亏。
学习路径建议：先吃透 K 线 + 均线 + 成交量（看盘三件套）→ 再学 MACD + KDJ/RSI（指标）→ 练量价关系与支撑压力（综合）→ 最后补财务估值（选股）。边看实盘边对照，比死记硬背有效得多。
