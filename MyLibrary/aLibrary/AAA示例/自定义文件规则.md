# 自定义文件规则说明

## xxx.url 外链文件内容规则

``` js
url: https://developer.mozilla.org/zh-CN/docs/Web/HTML/Element/video
cover: https://t13.baidu.com/it/u=4054909515,2945964656&fm=224&app=112&f=JPEG?w=500&h=500
title: 外链示例
tags: 外链, 示例
```

- `url` 是**跳转链接**（必填，http/https），`cover` 是**卡片封面**（可选）。
- 点卡片 / 目录树行直接新窗口打开；`cover` 可写外链图片地址或站内相对路径。

## xxx.link.md 导航页文件内容规则

一个 `.link.md` 文件 = 一组网站（书签导航页），打开后在内容区渲染成**导航连接卡片**，点卡片直接新窗口打开。
内容就是**普通 Markdown**：约定只有两条——`# 标题` 是分组，`[名称](地址)` 是一条书签，
后面可跟一个 `{…}` **自定义块**放图标和描述。

``` md
---
title: 常用开发导航        # 文首 front-matter（与 md 同款）：title / desc / tags / date
---

# 文档

[Vue.js](https://cn.vuejs.org/){![Vue](https://cn.vuejs.org/logo.svg) 前端渐进式框架}
[MDN Web Docs](https://developer.mozilla.org/zh-CN/){![MDN](https://developer.mozilla.org/favicon.ico) Web 技术权威文档}
[示例站点](https://example.com/){图标会自动取 /favicon.ico}

# 工具

[正则测试](https://jex.im/regulex/)
```

- **分组**：`#` ~ `######` 标题，其下的链接归入该组；分组顺序 = 标题在文件里的顺序。
  首个标题之前的链接归到最后的「其他」组；整个文件都没写标题时不显示分组标题，仍是一片整网格。
- **书签**：`[名称](https://…)`；名称与地址都是必填，缺名称或地址非 http/https 的行会被忽略。
- **`{…}` 自定义块**（可选，紧跟在链接后面）：
  - 开头的行内图片 `![说明](图标地址)` = **自定义图标**；
  - **其余文字整体作为描述**（显示在卡片上）；两者都可以只写一个，或都不写（写 `{}` 也行）。
- **导航图标**：不写自定义图标时，自动取该连接**根目录下的 `/favicon.ico`**。
  图标加载不出来时自动回退成网站名首字母色块，不出现破图。
- 行内的普通文字、`>` 引用、有序/无序列表等 markdown 写法都会被忽略；` ``` ` 围栏代码块整块跳过
  （示例文件里贴代码片段不会被当成书签）。
- 改完内容重跑 `kb:index` 生效；文件级元信息以导航文件为准（同 `.url` 的规矩）。
