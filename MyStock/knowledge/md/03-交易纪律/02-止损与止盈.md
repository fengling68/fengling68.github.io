# 止损与止盈

> 止损决定你能亏多少，止盈决定你能赚多久。两者都要在买入前想清楚。

## 一、止损的目的

止损不是承认判断错误，而是**控制单次决策错误的代价**。任何分析都存在概率失效的可能，止损是把"不确定"转化为"可承受"的工具。

## 二、常用止损方法

| 方法 | 规则 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 固定比例 | 亏损 8% – 10% 无条件离场 | 简单、可执行 | 易被震荡扫损 |
| 技术位 | 跌破关键支撑/MA20/前低 | 与市场结构一致 | 需判断支撑有效性 |
| ATR 波动止损 | 入场价 − 2×ATR(14) | 适应波动率差异 | 参数需调试 |
| 时间止损 | 持有 N 周未按预期上涨即离场 | 释放机会成本 | 对慢牛股不友好 |
| 逻辑止损 | 买入逻辑被证伪即离场 | 最本质 | 需要真正理解逻辑 |

**推荐组合：固定比例（底线）+ 逻辑止损（主导）。**

## 三、止损的纪律要点

1. 止损位在**买入前**确定，而不是亏损后寻找理由；
2. 触发即执行，不"再等一根 K 线"；
3. 亏损时**禁止向下摊薄成本**；
4. 止损后至少观察一个完整周期，避免情绪化反复进出；
5. 单笔亏损控制在总资金的 **1% – 2%** 之内（结合仓位管理）。

## 四、止盈方法

| 方法 | 说明 | 适用场景 |
| --- | --- | --- |
| 目标位止盈 | 到达估值目标全部或分批离场 | 价值型标的 |
| 移动止盈 | 从最高点回撤 X% 离场 | 趋势型标的 |
| 均线止盈 | 跌破 MA20 / MA60 离场 | 中线持有 |
| 分批止盈 | 达到目标先减 1/3，再涨再减 | 兼顾收益与安全 |
| 估值止盈 | 估值进入历史高分位区间逐步减仓 | 长线配置 |

**移动止盈示例：**

| 浮盈幅度 | 回撤容忍 |
| --- | --- |
| 0% – 10% | 固定止损 8% |
| 10% – 25% | 回撤 8% 离场 |
| 25% – 50% | 回撤 12% 离场 |
| > 50% | 跌破 MA20 离场 |

## 五、常见心理陷阱

- **处置效应**：赚一点就跑，亏很多却死扛 —— 与正确做法完全相反；
- **锚定成本价**：把买入价当作决策基准，忽视公司价值变化；
- **回本执念**：为"回本"承担更大风险，把小亏拖成大亏；
- **过度自信**：连续盈利后放大仓位、放宽止损。

## 六、交易记录模板

| 字段 | 说明 |
| --- | --- |
| 买入日期 / 价格 | 建立基准 |
| 买入逻辑 | 3 条以内，可验证 |
| 预期目标 | 估值或技术目标 |
| 止损位 | 明确数值 |
| 仓位比例 | 占总资金比例 |
| 卖出日期 / 价格 | 事后填写 |
| 复盘结论 | 逻辑是否成立，执行是否到位 |

> 交易系统 = 入场规则 + 仓位规则 + 退出规则。缺任何一项，长期结果都难以稳定。
