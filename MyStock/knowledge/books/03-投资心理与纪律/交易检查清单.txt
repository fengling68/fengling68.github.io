使用说明
----------------------------------------
本清单用于把交易纪律固化为可执行动作。每次下单前逐项打勾，
任意一项无法确认时，本次操作视为不通过，应当放弃或降低仓位。


【一】买入前检查（7 项，全部通过才允许下单）
----------------------------------------
[ ] 1. 我能否用三句话说清它的生意模式？
[ ] 2. 买入逻辑是否可验证、可证伪（不是"感觉会涨"）？
[ ] 3. 当前估值处于自身历史什么分位？是否低于 30%？
[ ] 4. 悲观情景下（收入 -20%、毛利率 -3pct）是否仍可接受？
[ ] 5. 经营现金流是否覆盖净利润？分红是否有自由现金流支撑？
[ ] 6. 单一标的仓位是否 ≤ 20%？单一行业是否 ≤ 35%？
[ ] 7. 是否已经写下明确的止损位与止损后的动作？


【二】持有期间检查（每周一次）
----------------------------------------
[ ] 1. 买入逻辑的三个条件是否仍然成立？
[ ] 2. 最近一期财报是否出现：应收账款增速 > 营收增速？
[ ] 3. 经营现金流与净利润是否持续背离？
[ ] 4. 大股东、管理层是否出现异常减持或高比例质押？
[ ] 5. 当前估值是否已进入历史 80% 分位以上（触发减仓）？


【三】卖出检查（满足任意一条即执行，不犹豫）
----------------------------------------
[ ] 逻辑证伪：核心竞争力消失、行业逻辑反转、财务造假嫌疑
[ ] 治理恶化：大额违规担保、资金占用、审计意见非标
[ ] 估值到顶：历史分位 > 90% 且盈利增速开始下滑
[ ] 纪律止损：跌破预先设定的止损位

注意：卖出与你的成本价无关。浮亏不是持有理由，浮盈不是卖出理由。


【四】情绪自检（下单前 30 秒）
----------------------------------------
[ ] 我是否因为连续盈利而想放大仓位？
[ ] 我是否因为怕错过（FOMO）而在没有计划的情况下追高？
[ ] 我是否因为想"回本"而准备向下摊薄成本？
[ ] 今天是否已经交易超过 2 次？（超过则强制停止）

以上任意一项为"是" → 暂停操作 24 小时。
