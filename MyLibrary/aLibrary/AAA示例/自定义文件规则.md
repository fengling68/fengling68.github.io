# 自定义文件规则说明

## xxx.url 外链文件内容规则

``` js
url: https://developer.mozilla.org/zh-CN/docs/Web/HTML/Element/video
cover: https://t13.baidu.com/it/u=4054909515,2945964656&fm=224&app=112&f=JPEG?w=500&h=500
title: 外链示例
tags: 外链, 示例
```

- `url` 是**跳转链接**（必填，http/https），`cover` 是**卡片封面**（可选）。
- 点卡片 / 目录树行直接新窗口打开；`cover` 可写外链图片地址或站内相对路径。

## xxx.link 导航页文件内容规则

一个 `.link` 文件 = 一组网站（书签导航页），打开后在内容区渲染成**导航连接卡片**，点卡片直接新窗口打开。
条目可用 `tags` 做**文件内分类**：内容区按标签分组，每组带一个小标题。

``` js
# `#` 开头的整行是注释；首个书签之前是「文件级配置」
title: 常用开发导航
desc: 点击卡片直接新窗口打开
tags: 导航, 示例
showLogo: true      # 是否展示网站 logo（真值，默认开启；写 false / no / 0 / off / 否 关闭）

# `- ` 开头的每一段是一条书签；条目 tags = 文件内分类标签（逗号分隔，可写多个）
- name: MDN Web Docs
  url: https://developer.mozilla.org/zh-CN/
  logo: https://developer.mozilla.org/favicon.ico
  desc: Web 技术权威文档
  tags: 文档, 前端
- name: Vue.js
  url: https://cn.vuejs.org/
  logo: https://cn.vuejs.org/logo.svg
  tags: 前端
- name: 示例站点
  url: https://example.com/
```

- 条目字段：`name`（网站名，必填）、`url`（网站连接，必填 http/https）、`logo`（网站 logo，可选）、
  `desc`（可选）、`tags`（文件内分类标签，可选）。
- **文件内分类（条目 `tags`）**：分组顺序 = 标签在文件里**首次出现**的顺序，组内保持文件内顺序；
  一条书签写了多个标签时，在它所属的**每个**组里各出现一次；没写 `tags` 的归到最后的「其他」组。
  全都没写 `tags` 时不显示分组标题，仍是一片普通网格（老文件不受影响）。
- 条目 `tags` 只管**文件内分组**，与文件级 `tags`（整页标签，供列表 / 搜索筛选）互不影响。
- `logo` 地址与 `.url` 的 `cover` 同规则：http(s) 外链图，或 `/`、`./` 开头的站内图（裸相对路径不认）。
- 文件级字段：`title` / `desc` / `tags` / `date` / `showLogo`；缺 `title` 时用文件名。
- 关掉 `showLogo` 或 logo 加载失败时，卡片回退为首字母色块，不出现破图。
- 键名大小写不敏感（`show_logo` / `show-logo` 等价）；缺 `name` 或 `url` 非 http/https 的条目会被丢弃。
