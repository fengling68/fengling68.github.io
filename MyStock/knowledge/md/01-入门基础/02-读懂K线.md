# 读懂 K 线

> K 线（蜡烛图）是最基础的价格记录方式：一根 K 线浓缩了某段时间内的四个关键价格与市场情绪。

## 一、K 线的四个价格

每根 K 线由 **开盘价、最高价、最低价、收盘价** 构成：

- **实体**：开盘价与收盘价之间的矩形，反映多空双方在该周期内的最终胜负；
- **上影线**：最高价到实体上沿，代表上方抛压；
- **下影线**：最低价到实体下沿，代表下方承接。

颜色约定（A 股）：**红涨绿跌** —— 收盘价高于开盘价画红（阳线），低于开盘价画绿（阴线）。

## 二、实体与影线的含义

| 形态特征 | 市场含义 |
| --- | --- |
| 长实体阳线 | 多方主导，买盘持续 |
| 长实体阴线 | 空方主导，抛压沉重 |
| 长上影 + 小实体 | 冲高回落，上方压力明显 |
| 长下影 + 小实体 | 探底回升，下方有承接 |
| 极小实体（十字星） | 多空胶着，方向待选择 |

## 三、常用单根与组合形态

### 单根形态

1. **锤子线**：出现在下跌末端，长下影、小实体、几乎无上影，意味着抛压被快速消化；
2. **倒锤子**：长上影，出现在下跌末端时预示反弹尝试；
3. **光头光脚阳线**：开盘即最低、收盘即最高，买方力量最强。

### 组合形态

- **早晨之星**：阴线 → 十字星 → 阳线，常见底部反转信号；
- **黄昏之星**：阳线 → 十字星 → 阴线，常见顶部反转信号；
- **红三兵**：连续三根递增阳线，趋势延续信号；
- **乌云盖顶**：阳线后高开低走的阴线，回吐前一日大半涨幅。

## 四、量价配合

K 线必须结合成交量看，单看形态容易误判：

| 量价组合 | 解读 |
| --- | --- |
| 价升量增 | 趋势健康，动能充足 |
| 价升量减 | 上涨乏力，警惕背离 |
| 价跌量增 | 恐慌抛售或主力出逃 |
| 价跌量减 | 抛压衰减，可能筑底 |
| 放量滞涨 | 上方存在明显套牢盘 |

## 五、使用要点

- **周期决定含义**：日线形态比 5 分钟线可靠，周线形态往往代表更大的资金意图；
- **位置决定有效性**：同样的锤子线，出现在长期下跌后比出现在上涨中段更有意义；
- **形态是概率不是确定性**：任何形态都需要结合位置、量能、基本面综合判断，并设置明确的止损。

## 六、常见误区

- 只看单根 K 线就下单，忽略整体趋势与所处位置；
- 把"十字星"当成必然反转，实际上它只代表分歧；
- 用短周期 K 线做长线决策，锚定效应会让判断严重失真。
